## 🚀 如何測試

### 1. 確保 MongoDB 運行中
```bash
mongod
```

### 2. 啟動後端服務
```bash
cd /Users/lishengfeng/Desktop/yolo/yolo1125
python backend/main.py
```

### 3. 測試管理者介面
1. 訪問: http://localhost:8000/login.html
2. 點擊「管理者登入」
3. 輸入帳號: `admin` / 密碼: `admin123`
4. 在使用者列表中點擊「📊 消費記錄」按鈕
5. 查看彈出的消費記錄 Modal

### 4. 測試客戶介面
1. 訪問: http://localhost:8000/login.html
2. 使用人臉識別登入(或註冊新使用者)
3. 登入後查看個人資訊卡片:
   - 本次消費
   - **累積消費**(顯示歷史總金額)
   - **註冊天數**(計算天數)
   - **🛍️ 最近購買**(顯示上一次購買的商品)
4. 點擊「📊 歷史消費」查看完整交易記錄
5. 點擊「🚪 登出」返回登入頁面

## 🔧 技術細節

### API 端點

#### 管理者 API
- `GET /api/admin/user/{user_id}/transactions` - 取得用戶交易記錄
  - 返回: 交易列表、統計摘要(總金額、總次數、總商品數)

#### 客戶 API (已存在)
- `GET /api/user/{user_id}/info` - 取得用戶詳細資訊
- `GET /api/user/{user_id}/transactions` - 取得交易歷史

### 資料庫結構

#### Transactions Collection
```javascript
{
    "_id": ObjectId,
    "user_id": ObjectId,           // 使用者 ID
    "user_name": str,              // 使用者姓名
    "items": [                     // 購買商品列表
        {
            "product_id": str,
            "product_name": str,
            "quantity": int,
            "unit_price": float,
            "subtotal": float
        }
    ],
    "total_quantity": int,         // 總數量
    "total_amount": float,         // 總金額
    "created_at": datetime         // 交易時間
}
```
