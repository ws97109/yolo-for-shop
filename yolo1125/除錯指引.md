# 使用者資訊顯示問題 - 除錯指引

## 🔍 問題診斷步驟

### 步驟 1: 確認系統運行
```bash
# 1. 確認 MongoDB 運行中
mongod

# 2. 確認後端服務運行中
cd /Users/lishengfeng/Desktop/yolo/yolo1125
python backend/main.py
```

### 步驟 2: 清除瀏覽器快取
1. 打開瀏覽器開發者工具 (F12 或 Cmd+Option+I)
2. 右鍵點擊重新整理按鈕 → 選擇「清除快取並強制重新整理」
3. 或使用 Cmd+Shift+R (Mac) / Ctrl+Shift+R (Windows)

### 步驟 3: 查看 Console 日誌

現在系統會輸出詳細的除錯訊息,請按照以下步驟檢查:

1. **打開瀏覽器 Console** (開發者工具 → Console 分頁)

2. **登入使用者後,應該會看到以下日誌**:
```
🔍 正在載入使用者詳細資訊... 6906be2bf101f516950903fd
📡 API 回應狀態: {userInfo: 200, transactions: 200}
📦 API 資料: {userInfo: {...}, transactions: {...}}
💰 累積消費: 3250 元
📊 交易記錄數量: 5
🛍️ 最近購買: [{...}]
📅 會員天數: 25 天 (註冊日期: 2025/10/12)
```

3. **如果看到錯誤訊息**:

#### 錯誤 A: `404 Not Found` 或 `500 Internal Server Error`
```
⚠️ 累積消費 API 失敗: {success: false, ...}
```
**解決方法**:
- 檢查後端是否正常運行
- 確認 MongoDB 中有該使用者的資料

#### 錯誤 B: `⚠️ 沒有交易記錄`
```
📊 交易記錄數量: 0
⚠️ 沒有交易記錄
```
**解決方法**:
- 該使用者還沒有購買記錄
- 執行測試腳本新增資料:
```bash
cd /Users/lishengfeng/Desktop/yolo/yolo1125
python scripts/add_test_transactions.py
```

#### 錯誤 C: `⚠️ 無法取得註冊日期`
```
⚠️ 無法取得註冊日期
```
**解決方法**:
- 該使用者的 `created_at` 欄位為空
- 檢查資料庫: `db.users.find({_id: ObjectId("...")}`

### 步驟 4: 手動測試 API

在瀏覽器 Console 中執行以下命令:

```javascript
// 取得當前使用者 ID (登入後執行)
const userId = "YOUR_USER_ID_HERE";

// 測試交易記錄 API
fetch(`/api/user/${userId}/transactions`)
  .then(r => r.json())
  .then(data => {
    console.log('交易記錄 API:', data);
    console.log('累積消費:', data.total_spent);
    console.log('交易數量:', data.total_transactions);
  });

// 測試使用者資訊 API
fetch(`/api/user/${userId}/info`)
  .then(r => r.json())
  .then(data => {
    console.log('使用者資訊 API:', data);
    console.log('註冊日期:', data.user.created_at);
  });
```

## 🛠️ 常見問題解決

### Q1: 所有值都是 "NT$ 0" 和 "0 天"
**原因**: API 沒有正確載入或使用者沒有資料
**解決**:
1. 檢查 Console 是否有錯誤訊息
2. 執行 `python scripts/add_test_transactions.py` 新增測試資料
3. 重新登入

### Q2: 累積消費顯示但沒有千分位
**原因**: 舊版 JavaScript 快取
**解決**: 清除瀏覽器快取並重新整理 (Cmd+Shift+R)

### Q3: 最近購買區域不顯示
**原因**: 該使用者沒有交易記錄
**解決**: 執行測試腳本或進行一次購買

### Q4: 會員天數計算錯誤
**原因**: 系統時間或資料庫時間不正確
**解決**:
```javascript
// 在 Console 檢查
const createdAt = new Date("2025-10-12T00:00:00Z");
const now = new Date();
const diffDays = Math.floor((now - createdAt) / (1000 * 60 * 60 * 24));
console.log('計算結果:', diffDays, '天');
```
